# Impulso Saludable

Videojuego educativo de acción tipo Wave con una interfaz de monitor cardíaco estilo Matrix.

## Ejecutar

Abre `index.html` en un navegador.

## Controles

- Mantén `Espacio`, `W` o `Flecha arriba` para subir.
- Suelta la tecla para bajar.
- Usa `X`, `F` o `Enter` para disparar.
- En móvil, mantén presionado el botón `MANTENER`.
